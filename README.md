# Automation Testing Practice – TesterBud

## Project Overview
This repository contains automation test scripts created for learning and practicing UI automation using a public practice website.

## Application Under Test
https://testerbud.com

## Tech Stack
- Playwright

## Disclaimer
This project is for educational purposes only.
The application under test is a public practice platform.
No real user or payment data is used.

## Test Coverage
- Navigation to practice page
- Product listing validation
- Add-to-cart functionality
- Checkout form validation
- UI assertions and basic scenarios
- used Page Object Model
- used selector getByRole, getByPlaceholder, getByLabel, XMl, Loctors (id, css)
